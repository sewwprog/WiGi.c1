# WiGi.c1 — Python Серверне Середовище

Термінальний менеджер та повноцінний Python-сервер, який запускається на ноутбуці або будь-якій машині з Python 3.10+. Працює на стандартній бібліотеці Python — жодних сторонніх пакетів встановлювати не потрібно.

## Запуск прямо з GitHub в Ubuntu (WSL на Windows / Linux)

Відкрий термінал **Ubuntu** на Windows і встав одну команду (вона сама скачає або оновить репозиторій з GitHub та відкриє інтерактивне меню):

```bash
git clone https://github.com/sewwprog/WiGi.c1.git ~/WiGi.c1 2>/dev/null || git -C ~/WiGi.c1 pull; cd ~/WiGi.c1 && python3 main.py
```

Або через авто-скрипт `run.sh`:
```bash
curl -fsSL https://raw.githubusercontent.com/sewwprog/WiGi.c1/main/run.sh | bash
```

## Можливості Термінального Менеджера (`python3 main.py`)

1. **Створити новий сервер** — задаєш **назву**, **пароль** (`PBKDF2-HMAC-SHA256`) та порт (за замовчуванням `8000`). Автоматично ініціалізується ізольоване робоче середовище `servers/<slug>/`.
2. **Вибрати вже створений сервер** — перевірка пароля та запуск на поточному пристрої (`localhost` + локальна мережа `LAN IP`).
3. **Керування сервером** — перейменування, зміна опису, зміна пароля, зміна порту, **клонування середовища сервера** під новою назвою.
4. **Видалення сервера** — із захистом паролем.

## 🖥 Розширення WiGi OS — Веб-Операційна Система (`/os`)

На кожному запущеному сервері доступна повноцінна **HTML5 операційна система WiGi OS** за адресою **`http://localhost:8000/os`** (або кнопкою **«🚀 Відкрити WiGi OS»** у верхній панелі сервера):
- **Повноцінний віконний менеджер** — перетягування, зміна розміру, згортання у таскбар, розгортання на весь екран, поділ екрана навпіл (`◧` / `◨` Snap Left/Right), контекстне меню правою кнопкою, швидкий пошук по додатках і файлах (`Ctrl + K`), екран блокування та 5 тем робочого столу.
- **10 реальних робочих додатків, підключених до сервера:**
  1. **Code Studio (IDE)** — вкладки, дерево файлів, нумерація рядків та позиція курсора, HTML/CSS-сніпети, **живе split-прев’ю HTML** зі стилями й зображеннями сайту, `Ctrl + S`, запуск Python.
  2. **🖥 Термінал ОС** — повноцінна консоль із підтримкою переходу між папками (`cd`), історією команд (`↑`/`↓`) та запуском скриптів.
  3. **Провідник** — сітка/список, пошук, клікабельні breadcrumbs, прев’ю зображень, завантаження/скачування і шаблони проєктів.
  4. **🐙 GitHub Studio** — клонування реп з GitHub (`owner/repo`), `git init`, `status`, `pull`, `commit`, `push`, перемикання гілок і миттєве відкриття репи в Code Studio або Терміналі.
  5. **📋 Задачі Kanban** — робоча дошка задач (`Заплановано` / `В роботі` / `Готово`) зі збереженням на сервері.
  6. **📝 Нотатки MD** — редактор Markdown із живим прев'ю та збереженням у `.md` файли середовища.
  7. **Браузер WiGi** — вкладки, закладки створених доменів, внутрішній WiGi DNS, перемикач десктоп/планшет/телефон, редагування у Code Studio; локальні HTML-проєкти теж відкриваються з `/workspace/...`.
  8. **Сайти & Домени** — сайт із шаблону або існуючої папки, прив’язка власного домену, лічильник відвідувань, online/чернетка, редагування коду, публічне посилання, DNS/hosts-підказки.
  9. **📊 Монітор ОС** — живий моніторинг CPU, RAM, диска та таблиця активних процесів хоста (`ps`).
  10. **⚙️ Налаштування ОС та ENV** — зміна теми шпалер і редактор змінних середовища сервера (`ENV`).

## Мій HTML-файл → будь-яке локальне ім’я

Це **окремий режим** від публікації сайту за справжнім інтернет-доменом:

1. У WiGi OS відкрий **Code Studio**, створи й збережи, наприклад, `my-project/page.html` (`Ctrl+S`). Натисни **«Прив’язати домен»** біля кнопки відкриття HTML. Або зайди в **«Сайти & Домени» → «Прив’язати свій HTML-файл до домену» → «Вибрати HTML»** і знайди файл у папках.
2. Введи **будь-яке коректне локальне доменне ім’я** на свій смак: `game`, `my-game.local`, `portfolio.ua`. Натисни **«Прив’язати локально»**. Файл не копіюється і не перезаписується: його вміст віддається за `/` вибраного імені; CSS, JS, картинки з його папки підтягуються відносними шляхами. Прямо з картки можна відкрити результат у **WiGi Browser** або повернутися до редактора.
3. **У браузері WiGi OS** набери `game` — внутрішній DNS відкриє вибраний HTML одразу. **У звичайному браузері на цьому комп’ютері** без налаштувань відкрий `http://game.localhost:8000/` (точна адреса alias показана в картці). Якщо хочеш бачити в адресному рядку *саме* `game` чи `portfolio.ua`, додай `127.0.0.1 game` або `127.0.0.1 portfolio.ua` до `/etc/hosts` (Windows: `C:\Windows\System32\drivers\etc\hosts`) і відкрий `http://game:8000/` / `http://portfolio.ua:8000/`. `.localhost` та hosts налаштовуються **лише на твоєму комп’ютері**; це не реєстрація справжнього домену, і HTTPS тут немає.
4. Локально прив’язаний сайт відповідає лише на підключення із **loopback** (`127.0.0.1` / `::1`); запити з LAN відхиляються з `403`. Для приватної роботи запускай сервер з `--host 127.0.0.1` і **не публікуй його через тунель/reverse proxy**: проксі на цій же машині може звертатися до сервера як loopback і обійти мережеве обмеження. Якщо файл лежить безпосередньо в корені workspace, віддається лише сам HTML (для CSS/JS поклади проєкт в окрему папку). Для файлу в окремій папці дозволені його статичні ресурси, але не інші HTML/приватні файли.

## Сайти і власні домени в WiGi OS

1. Відкрий `http://localhost:8000/os`, увійди за паролем та запусти **Сайти & Домени** (іконка з власним SVG-дизайном).
2. Введи домен (`myshop.ua`, `portfolio.dev`, `nexus.wigi`), назву і шаблон: **лендінг / магазин з кошиком / портфоліо / блог / web app / порожній**. HTML, CSS і JS створяться в `servers/<сервер>/sites/<домен>/`. Можна вказати власну папку з `index.html` — файли не перезаписуються. Відкрий їх у Code Studio, редагуй і одразу переглядай результат.
3. Сайт доступний без логіна через **`http://localhost:8000/s/myshop.ua/`** (цей URL можна відкрити і через зовнішній HTTPS reverse proxy). У браузері WiGi OS просто введи `myshop.ua` — внутрішній DNS перенаправить на локальний сайт. Для Chrome/Edge/Firefox на тому самому комп’ютері використовуй **`http://myshop-ua.localhost:8000/`**; через LAN також підтримуються alias на `.nip.io` / `.sslip.io`.
4. Для **реального доступу через `myshop.ua` в інтернеті** потрібні: власність на домен, DNS A-запис на публічний IP хоста, відкритий порт (або reverse proxy на 80/443), TLS-сертифікат для HTTPS. WiGi визначає сайт за HTTP-заголовком `Host`; сама програма не купує домен, не змінює зовнішній DNS та не видає TLS-сертифікат. Для локальної перевірки можна додати `127.0.0.1 myshop.ua` у `/etc/hosts` (Windows: `C:\Windows\System32\drivers\etc\hosts`) і відкрити `http://myshop.ua:8000/`.
5. Керуй через авторизовані `GET /api/sites` і `POST /api/sites/create`, `/api/sites/update`, `/api/sites/delete`. Публічний `/s/<domain>/` і віртуальні хости віддають тільки файли зареєстрованої папки; офлайн-режим повертає `503`.

> **Безпека:** опубліковані файли доступні всім без пароля. Не клади в папку сайту секрети, `.env`, бази даних або приватні документи. Python-команди і файловий редактор залишаються за авторизацією сервера.

## Можливості Блоку Сервера (Класична панель `/` + REST API)

Після входу за паролем сервера відкривається інтерактивне середовище з 5 розділами:
- **Огляд системи** — час роботи, адреси підключення, моніторинг CPU / RAM / диска, керування активними сесіями (скидання чужих підключень), журнал подій у реальному часі.
- **Файли та Код** — повноцінний файловий менеджер і редактор коду в межах папки сервера (`створення`, `редагування з Ctrl+S`, `завантаження/скачування файлів`, `перейменування`, `видалення`, запуск `.py` файлів у один клік).
- **Термінал / Python** — виконання shell-команд у середовищі сервера з історією команд (`↑`/`↓`) та миттєвий запуск Python-фрагментів.
- **Git / GitHub** — клонування будь-яких репозиторіїв з GitHub (`owner/repo` або URL), створення нових реп (`git init`), перегляд змінених файлів і комітів, кнопки `Status`, `Pull`, `Commit`, `Push` та перемикання гілок.
- **Налаштування та ENV** — змінні середовища сервера (`KEY=VALUE`, автоматично передаються в Python, термінал та Git), зміна назви/порту/пароля та віддалена зупинка сервера.
