# WiGi.c1 — Python Серверне Середовище

Термінальний менеджер та повноцінний Python-сервер, який запускається на ноутбуці або будь-якій машині з Python 3.10+. Працює на стандартній бібліотеці Python — жодних сторонніх пакетів встановлювати не потрібно.

## Запуск прямо з GitHub в Ubuntu (WSL на Windows / Linux)

Відкрий термінал **Ubuntu** на Windows і встав одну команду (вона сама скачає або оновить репозиторій з GitHub та відкриє інтерактивне меню):

```bash
git clone https://github.com/sewwprog/WiGi.c1.git ~/WiGi.c1 2>/dev/null || git -C ~/WiGi.c1 pull; cd ~/WiGi.c1 && python3 main.py
```

Або через авто-скрипт `run.sh`:
```bash
curl -fsSL https://raw.githubusercontent.com/sewwprog/WiGi.c1/main/run.sh | bash
```

## Можливості Термінального Менеджера (`python3 main.py`)

1. **Створити новий сервер** — задаєш **назву**, **пароль** (`PBKDF2-HMAC-SHA256`) та порт (за замовчуванням `8000`). Автоматично ініціалізується ізольоване робоче середовище `servers/<slug>/`.
2. **Вибрати вже створений сервер** — перевірка пароля та запуск на поточному пристрої (`localhost` + локальна мережа `LAN IP`).
3. **Керування сервером** — перейменування, зміна опису, зміна пароля, зміна порту, **клонування середовища сервера** під новою назвою.
4. **Видалення сервера** — із захистом паролем.

## 🖥 Розширення WiGi OS — Веб-Операційна Система (`/os`)

На кожному запущеному сервері доступна повноцінна **HTML5 операційна система WiGi OS** за адресою **`http://localhost:8000/os`** (або кнопкою **«🚀 Відкрити WiGi OS»** у верхній панелі сервера):
- **Повноцінний віконний менеджер** — перетягування, зміна розміру, згортання у таскбар, розгортання на весь екран, поділ екрана навпіл (`◧` / `◨` Snap Left/Right), контекстне меню правою кнопкою, швидкий пошук по додатках і файлах (`Ctrl + K`), екран блокування та 5 тем робочого столу.
- **9 реальних робочих додатків, підключених до сервера:**
  1. **💻 Code Studio (IDE)** — дерево файлів, вкладки відкритих файлів, нумерація рядків, збереження по `Ctrl + S`, запуск `.py` на сервері та відкриття `.html` у браузері ОС.
  2. **🖥 Термінал ОС** — повноцінна консоль із підтримкою переходу між папками (`cd`), історією команд (`↑`/`↓`) та запуском скриптів.
  3. **📁 Провідник** — візуальний менеджер файлів із завантаженням/скачуванням та генератором шаблонів Python і HTML проєктів у 1 клік.
  4. **🐙 GitHub Studio** — клонування реп з GitHub (`owner/repo`), `git init`, `status`, `pull`, `commit`, `push`, перемикання гілок і миттєве відкриття репи в Code Studio або Терміналі.
  5. **📋 Задачі Kanban** — робоча дошка задач (`Заплановано` / `В роботі` / `Готово`) зі збереженням на сервері.
  6. **📝 Нотатки MD** — редактор Markdown із живим прев'ю та збереженням у `.md` файли середовища.
  7. **🌐 Веб-Ранер HTML** — вбудований браузер для живого запуску твоїх HTML/CSS/JS проєктів прямо із папки сервера (`/workspace/...`).
  8. **📊 Монітор ОС** — живий моніторинг CPU, RAM, диска та таблиця активних процесів хоста (`ps`).
  9. **⚙️ Налаштування ОС та ENV** — зміна теми шпалер і редактор змінних середовища сервера (`ENV`).

## Можливості Блоку Сервера (Класична панель `/` + REST API)

Після входу за паролем сервера відкривається інтерактивне середовище з 5 розділами:
- **Огляд системи** — час роботи, адреси підключення, моніторинг CPU / RAM / диска, керування активними сесіями (скидання чужих підключень), журнал подій у реальному часі.
- **Файли та Код** — повноцінний файловий менеджер і редактор коду в межах папки сервера (`створення`, `редагування з Ctrl+S`, `завантаження/скачування файлів`, `перейменування`, `видалення`, запуск `.py` файлів у один клік).
- **Термінал / Python** — виконання shell-команд у середовищі сервера з історією команд (`↑`/`↓`) та миттєвий запуск Python-фрагментів.
- **Git / GitHub** — клонування будь-яких репозиторіїв з GitHub (`owner/repo` або URL), створення нових реп (`git init`), перегляд змінених файлів і комітів, кнопки `Status`, `Pull`, `Commit`, `Push` та перемикання гілок.
- **Налаштування та ENV** — змінні середовища сервера (`KEY=VALUE`, автоматично передаються в Python, термінал та Git), зміна назви/порту/пароля та віддалена зупинка сервера.
