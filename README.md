# WiGi.c1 — Python Серверне Середовище

Термінальний менеджер та Python-сервер, який запускається на ноутбуці або будь-якій машині, де встановлено Python 3.10+. Не потребує сторонніх бібліотек — працює одразу після клонування.

## Швидкий старт у терміналі

```bash
python3 main.py
```
*(на Windows: `python main.py`)*

Після запуску в терміналі відкривається інтерактивне меню:
1. **Створити новий сервер** — вводиш **назву** та **пароль** (і за бажанням порт, за замовчуванням `8000`). Для сервера автоматично створюється окрема робоча папка `servers/<slug>/`.
2. **Вибрати вже створений сервер** — обираєш сервер зі списку, вводиш його пароль і він запускається на поточному пристрої (`127.0.0.1` + локальна мережа `LAN IP`).
3. **Видалити сервер** — видалення профілю сервера після підтвердження паролем.

## Доступ до запущеного сервера

Коли сервер працює, в терміналі показуються дві адреси:
- **Локально (на цьому ноуті):** `http://127.0.0.1:8000`
- **У локальній мережі:** `http://<IP-ноута>:8000`

При переході за посиланням відкривається сторінка входу за паролем сервера та панель середовища.

## Запуск через аргументи командного рядка (опціонально)

```bash
# Переглянути список створених серверів
python3 main.py --list

# Створити сервер без меню
python3 main.py --create "MyServer" --password "secret" --port 8000

# Одразу запустити створений сервер
python3 main.py --start "MyServer" --password "secret"
```
