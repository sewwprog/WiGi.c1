# StoneLand II — Імперський портал

Адаптивний інформаційний сайт Імперії StoneLand II.

## Запуск
Відкрийте `index.html` у браузері. Жодних збірок або платних сервісів не потрібно.

## Розділи
- Імперія та цінності
- Устрій
- Хроніка
- Кодекс
- Приєднання (генерує текст заявки для копіювання — не надсилає її автоматично)

## Налаштування
Текст, назви, структура та повідомлення редагуються в `index.html`.
Для публікації через GitHub Pages оберіть **Settings → Pages → Deploy from a branch → main / root**.
Жодні реальні IP-адреси, імена правителів чи запрошення не вигадані; додайте перевірену інформацію перед публікацією.

Сайт розроблено без бекенду. Для повноцінної системи заявок потрібен окремий сервер або інтеграція.
