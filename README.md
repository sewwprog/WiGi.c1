# StoneLand II — сайт Minecraft сервера

Повністю адаптивний сайт у піксельному Minecraft-стилі з **окремими екранами**:
**Головна / Новини / Галерея / Спільнота / Кабінет / Адмінпанель**.
IP сервера ніде не вказаний.

## Статус підключення

- Створений окремий безкоштовний Supabase-проєкт StoneLand II:
  https://supabase.com/dashboard/project/spfpwknvesclrmjcbwce
- Frontend `config.js` **вже** підключений до цього проєкту через public publishable key.
- `supabase/schema.sql` **вже виконано** в базі: таблиці, RLS, профілі та Storage налаштовані.
- Залишилося змінити **Confirm email** у Dashboard і створити первинного адміністратора.
- **Не виконуй `supabase/schema.sql` вдруге без потреби.**
- Права адміністраторів визначає таблиця `sl2_admins`, а не текст нікнейму в браузері.
- Усі паролі зберігає Supabase Auth (bcrypt); жодних паролів або server secret у коді GitHub немає.

## ОБОВ'ЯЗКОВО: увімкнути вхід без пошти

Відкрий: https://supabase.com/dashboard/project/spfpwknvesclrmjcbwce/auth/providers

1. У розділі **Email** залиш увімкненим **Enable Email provider**.
2. **Вимкни «Confirm email»** і збережи. Це потрібно для реєстрації за логіном і паролем без справжньої пошти.
3. На сайті від користувача потрібні тільки **логін і пароль**. Фоновий ідентифікатор `nickname@stoneland.invalid` утворюється автоматично та не отримує листів.

**Увага:** якщо реєструватися до вимкнення «Confirm email», акаунт може залишитися непідтвердженим, тому спочатку зміни налаштування.

## Перший адміністратор SeWapro

Оскільки зарезервований логін не можна зареєструвати через публічну форму, потрібно один раз створити адміна в Supabase Dashboard. **Не використовуй пароль, який вже надсилав у чаті: придумай інший, довший і унікальний.**

1. У **Supabase → SQL Editor** виконай `supabase/prepare-admin.sql`. Він тимчасово вимикає тільки тригер автостворення профілю, щоб дозволити створити зарезервований логін.
2. **Одразу** відкрий https://supabase.com/dashboard/project/spfpwknvesclrmjcbwce/auth/users → **Add user**:
   - Email: `sewapro@stoneland.invalid` (внутрішній Auth-ідентифікатор, його не потрібно вводити на сайті).
   - Password: твій **новий надійний пароль**.
   - Познач **Auto Confirm user** / email confirmed.
3. **Одразу** повернись до SQL Editor і виконай `supabase/finish-admin.sql`. Цей скрипт відновить тригер, створить профіль і надасть права адміна UUID нового акаунта. Наприкінці має повернути 1 рядок зі значенням `sewapro`.
4. Тепер відкрий сайт → **Кабінет → Увійти**, введи `SeWapro` та новий пароль. З'явиться кнопка **Адмінпанель**.

**Важливо:** не залишай тригер вимкненим і не запускай відкриту реєстрацію між кроками 1 і 3. Якщо користувача створити не вдалося, усе одно виконай `supabase/finish-admin.sql`, щоб відновити тригер (SQL може повідомити, що користувача ще немає).

## Що працює після активації

- Користувачі створюють акаунти лише за логіном і паролем, без введення пошти.
- Сесія зберігається після перезавантаження браузера.
- Публічні новини та скріншоти, профілі учасників.
- Адмінправа на **новини** і **галерею** через RLS, а не просто приховану кнопку.
- Фото JPEG/PNG/WebP до 5 МБ у `sl2-gallery`.
- Видалення новин та фотографій адміністратором.

Список учасників не містить електронних адрес. Оскільки у гравців немає відновлюваної пошти, забутий пароль можна скинути тільки за допомогою власника Supabase-проєкту через Dashboard. Увімкни у Dashboard Auth rate limits / CAPTCHA, якщо з'явиться спам.

## Структура

- `index.html` — усі окремі екрани/форми
- `styles.css` — адаптивний темний Minecraft-дизайн
- `app.js` — навігація, вхід, новини, фото, адмінка
- `config.js` — публічна адреса й publishable key виділеного Supabase-проєкту
- `supabase/schema.sql` — **вже застосована** схема з RLS
- `supabase/prepare-admin.sql`, `supabase/finish-admin.sql` — два кроки створення адміна
- `assets/` — графіка у піксельному стилі

## Перевірка

1. Створи звичайного гравця, увійди та онови сторінку — сесія має залишитися.
2. Перевір, що звичайний гравець не може змінити новини навіть напряму через API.
3. Після адміністраторського налаштування увійди як SeWapro й додай першу новину/фото.
4. Перевір, що без входу всі бачать ці матеріали.
